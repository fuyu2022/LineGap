LINE GAP - Web edition

Serve this entire directory through HTTP or HTTPS. Do not double-click
index.html: file:// cannot load the game's WebAssembly/data reliably.

Windows local preview (Python required): double-click preview.cmd and open
http://127.0.0.1:4265 in a current Chrome, Edge or Firefox browser.

WASD / Arrows: move. Left mouse / Space: dash. Space: start/restart/resume.
Esc: pause/resume. R: restart. Click English / 中文 to switch language.

Click the game or press Space to enable audio. Background music loops
continuously. Music: On / Off controls only music; sound effects stay enabled.
The music toggle preserves its playback position and saves your choice.
Records and preferences are stored in this browser's site data (IndexedDB).

This single-threaded build does not require special cross-origin headers.
For GitHub Pages, publish all files with index.html at the site root;
all resource URLs are relative and support a repository subdirectory.
In branch-based Pages publishing, include the .nojekyll file.
