# 线隙 · LINE GAP

版本：`v0.2.3-beta`。一个由点、线、圆环组成的 Godot 生存游戏。

[在线游玩](https://fuyu2022.github.io/LineGap/)

## 操作

- WASD / 方向键：移动。
- 鼠标左键 / 空格：冲刺；空格也用于开始、重开和继续。
- ESC：暂停 / 继续；切换窗口时自动暂停。
- R：重开。
- 打开右下角“设置”切换中英文和背景音乐，选择自动保存。游戏中打开设置会暂停，关闭后恢复。音乐开关不影响音效；网页版首次点击或按键后启用声音。

安卓版横屏游玩：场地铺满屏幕，数字直接显示在顶部，最高纪录以“得分 / 击碎数 / 存活时间”显示。左侧轮盘移动，右侧按钮冲刺，按钮内显示冷却秒数。右上角设置中可选择普通 / 音乐模式、固定 / 跟随轮盘、音乐和语言，选择自动保存。切换游戏模式会重开本局，设置界面继续保持暂停，关闭后再游玩。跟随轮盘以首次按下的位置为中心，整次拖动中中心保持固定，推杆只决定方向，偏离中心即固定满速；松开后轮盘收起，下次按下重新确定中心。支持双指同时移动和冲刺。轮盘和冲刺按钮采用更小的默认尺寸，按可用屏幕短边自适应，并按最终显示尺寸和屏幕密度限制上限：轮盘外圈直径最多 120dp，冲刺按钮直径最多 100dp，画面整体放大时也不会超过上限；文字和触控范围同步变化；固定轮盘也采用偏离中心即固定满速的规则。

安卓物体和特效尺寸为 PC 基础值的 3 倍，基础移速为 1.5 倍（502.5 像素/秒），一、二阶段冲刺距离为 240 像素，三阶段为 420 像素。旋转障碍转速为原来的 1/2。障碍按实际长度安排生成边距，旋转障碍完整留在场地内，物体和特效统一裁切到场地。音乐模式右侧按钮显示“波纹”，释放后变灰，每拍恢复，支持 230 毫秒合拍容错和 80 毫秒提前输入缓存；三阶段波纹半径为 330 / 540 / 750 像素。

## 玩法

躲避白色实线，金色虚线为预警。光球每个加 50 分、增加一条命并清空冲刺冷却，最多三条命；存活每秒加 10 分。受伤后获得 2 秒保护，最后一条命耗尽时结束。

- 一条命：冲刺使障碍暂时虚化，距离 160 像素，冷却 1.5 秒。
- 两条命：冲刺可击碎障碍，冷却减为 0.75 秒。
- 三条命：保留击碎能力，冲刺距离增加到 280 像素。

每击碎一个障碍物获得 **15 分**。

右下角新增“音乐模式”按钮，金色表示开启；切换模式会重开本局，选择自动保存。普通模式和音乐模式分别保存最高纪录。
PC 和网页顶部的最高纪录采用“得分 / 击碎数 / 存活时间”格式，时间保留一位小数，例如 `00820 / 025 / 123.4秒`。三个数值分别取各自历史最高值。

音乐模式下，场地边框、玩家外圈和光球跟随背景音乐节拍呼吸。左键 / 空格释放向外扩散的波纹，不再产生位移；也可点击底部“波纹”按钮。每拍可释放一次，使用后按钮变灰，在下一拍恢复。拍点前后 230 毫秒内释放会让全部障碍短暂虚化，波纹触及虚化障碍时击碎；未合拍的波纹照常出现，但不能击碎实线。按钮灰色时，距离下一次可用拍点不超过 80 毫秒的输入会缓存一次，在拍点自动释放；连续按不会叠加，暂停、失焦、重开和结束会清空缓存。虚化结束后，未击碎的障碍恢复碰撞。初始为一阶段，三阶段波纹半径分别为 110 / 180 / 250 像素，收集光球仍提升阶段和生命。

音乐模式每收集 7 个光球进入 7 秒“超级共振”：障碍持续虚化，并在每个拍点自动击碎，不再增加移动速度。暂停会同时冻结音乐和游戏；关闭背景音乐只静音，节拍继续运行。PC 和网页使用同一份音乐节拍数据，网页版仍需首次点击或按键启用音频。

每收集 7 个光球进入 **7 秒超级冲刺状态**：移动速度为普通状态的 **2 倍**，全程无敌、冲刺无冷却，接触障碍即可击碎。冲刺仍需手动按空格或点击鼠标触发，冲刺中可转向。状态条和拖尾变为金色；结束后恢复普通移动速度，再获得 2 秒保护。暂停冻结计时，重开清空本局进度。最高得分、单局最多击碎数和最长存活时间分别保存。

## 本地运行与打包

源码用 Godot 4.7.2 打开 `project.godot`，或双击 `play.cmd` 游玩、`editor.cmd` 编辑。打包需安装匹配的导出模板：

```powershell
.\build.ps1      # Windows x64 免安装版
.\build-web.ps1  # Web 版
.\build-android.ps1 # Android APK
```

脚本可通过 `-GodotPath` 指定引擎路径，输出到 `builds/`，文件名自动读取版本号。Windows 版解压后运行 `LineGap.exe`，保留同目录的 `LineGap.pck`。

Android 需 JDK 17、Android SDK（含 Build Tools 35.0.1）和对应导出模板。可用 `-JavaPath` 与 `-AndroidSdkPath` 指定路径。构建脚本复用本机发布签名，保存在 `%LOCALAPPDATA%\LineGap\android-signing`，不要删除；密码由当前 Windows 账户加密保存。发布新版时同步递增 `export_presets.cfg` 的 Android `version/code`。

Web 版需发布整个 `builds/LineGap-Web/` 目录，不能直接双击 HTML。本地预览可运行导出目录里的 `preview.cmd`（需要 Python）。测试脚本在 `tests/`，截图和报告在 `artifacts/`。

## GitHub Pages

在 [Pages 设置](https://github.com/fuyu2022/LineGap/settings/pages) 中将 Source 设为 **GitHub Actions**。推送源码到 `main` 后，工作流会自动导出并发布 Web 版；在 [Actions](https://github.com/fuyu2022/LineGap/actions) 查看进度。无需提交 `builds/`，也无需额外配置 Token。
